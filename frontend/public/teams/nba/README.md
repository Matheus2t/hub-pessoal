# Logos oficiais NBA

Origem: https://cdn.nba.com/logos/nba/{teamId}/primary/L/logo.svg

Cópias obtidas em 31/10/2026. Os nomes são os IDs oficiais NBA. O mapeamento
de siglas está em backend/app/sports_assets.py. A autorização para os escudos
dos clubes, adversários e classificações foi confirmada pelo responsável do projeto.

Os SVGs são servidos localmente para evitar falhas de HTTP/2 do CDN no navegador.
Não há credenciais nem chamadas à API para carregar estas imagens.
